# QuarterPlan

Get exact fiscal quarter dates, week and day counts, OKR presets, a milestone checklist, and a live quarter progress bar. Free quarter planner.

## Features
- Exact quarter start/end dates with total weeks and days for any year
- One-click OKR cadence presets for each quarter
- Milestone checklist plus a live progress bar for the current quarter
